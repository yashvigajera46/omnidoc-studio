# OmniDoc Studio

An AI-powered document generation and study assistant web application built with Python, FastAPI, and ReportLab.

## Features

- **Document Processing**: Generates formatted, publication-ready study materials.
- **ReportLab PDF Export**: Creates downloadable, structured PDF summaries and documents.
- **Interactive UI**: Simple web interface served directly via FastAPI static files.
